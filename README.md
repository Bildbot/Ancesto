# 🌳 Родословная — Семейный архив и Генеалогическое древо

Интерактивное веб-приложение для составления родословной, ведения семейного архива, умного распознавания лиц на исторических и современных фотографиях и хронологии поколений.

## ✨ Ключевые возможности

### 1. 🌲 Интерактивное генеалогическое древо
- Панорамирование, масштабирование (zoom/pan) и центрирование фокуса на любой ветке или персоне.
- Поддержка кровных, супружеских, приёмных и кастомных родственных связей.
- Быстрое добавление родственников прямо из узлов древа (родитель, ребёнок, супруг, брат/сестра).

### 2. 🧠 Нейросетевое распознавание лиц (Face-API)
- Детекция лиц на фотографиях с использованием нейросетей TinyFaceDetector и SSD MobileNet.
- 68 лицевых ориентиров (landmarks) и извлечение 128-мерных дескрипторов лиц для сравнения.
- Локальное хранение весов моделей в папке `public/models/` с автоматическим резервным переключением на CDN.
- Умный поиск совпадений лиц среди членов семьи (режим Tonfotos).
- Автоматическая перелинковка и синхронизация фотографий между карточками отмеченных персон.

### 3. 🖼️ Умные портреты персоналий
- Автоматическое вычисление координат центра лица (`centerX`, `centerY`) из найденных bounding box.
- Интеллектуальное кадрирование (`object-fit: cover`, `object-position`, динамический зум `scale`), гарантирующее идеальное центрирование лица в миниатюрах карточек и списках родни.
- Возможность кадрирования и назначения портрета прямо из архива снимков.

### 4. 🕸️ Интерактивный граф связей (Network Graph)
- Визуализация сложной семейной структуры как единой сети взаимосвязей.
- Подсветка прямых связей и окружения выбранного человека.

### 5. ⏳ Хроника поколений (Timeline)
- Временная шкала ключевых дат, событий, вех жизни и исторических документов.

### 6. 📁 Архив медиафайлов и документов
- Хранение сканов метрических книг, наградных листов, свидетельств и фотоальбомов.
- Полноэкранный просмотрщик (Lightbox) с возможностью ручной разметки лиц.

### 7. 💾 Полная конфиденциальность и автономность (PWA & IndexedDB)
- Все данные и фотографии хранятся локально в IndexedDB браузера — никакие персональные данные не передаются на сторонние серверы без вашего ведома.
- Резервное копирование и экспорт всей базы в единый JSON-файл.
- Экспорт GEDCOM 5.5.1 с семейными записями, родителями, детьми и супругами. GEDCOM не включает медиа, теги, координаты лиц, значимые даты, социальный статус и часть нестандартных связей (например, крёстных, братьев/сестёр и произвольные связи); пол `other` передаётся как `U`. Приёмные отношения передаются отметкой `PEDI adopted`, которую принимающее приложение может интерпретировать по-своему.
- Поддержка режима PWA (Progressive Web App) для установки на смартфоны и планшеты.
- Возможность компиляции в легковесный нативный Windows EXE через встроенный `compile-exe.bat`.

## 🛠️ Стек технологий

- **Фронтенд**: React 19, TypeScript
- **Сборщик**: Vite 8
- **Стилизация**: Tailwind CSS v4
- **Компьютерное зрение**: `@vladmandic/face-api` (TinyFaceDetector, FaceLandmark68, FaceRecognitionNet)
- **Иконки**: Lucide React
- **Хранилище данных**: IndexedDB (браузерное локальное хранилище)

## 🚀 Быстрый старт

### Требования
- Node.js 18+ (рекомендуется Node.js 22)
- npm

### Установка зависимостей
```bash
npm install
```

### Запуск сервера разработки
```bash
npm run dev
```
Приложение откроется по адресу `http://localhost:3000`.

### Сборка для продакшена
```bash
npm run build
```
Собранные статические файлы будут находиться в папке `dist/`.

### Проверка типов и линтинг
```bash
npm run lint
```

## 💻 Запуск на Windows без установки сложных инструментов

В проекте предусмотрены удобные скрипты для Windows:
1. `start-windows.bat` — быстрый запуск приложения на компьютере с Windows.
2. `compile-exe.bat` — компиляция нативного исполняемого файла `Rodoslovnaya.exe` (~25 КБ) с использованием встроенного компилятора Windows .NET C# (`csc.exe`) без сторонних сборщиков.

## 📂 Структура проекта

```
├── public/
│   ├── models/            # Веса нейросетей распознавания лиц
│   ├── icon.svg           # Иконка приложения
│   ├── manifest.json      # Манифест PWA
│   └── sw.js              # Service Worker для работы оффлайн
├── src/
│   ├── components/
│   │   ├── common/        # Общие компоненты (кнопка установки PWA и др.)
│   │   ├── media/         # Просмотрщик фото с разметкой лиц (PhotoFaceViewer)
│   │   ├── modals/        # Модальные окна (карточка персоны, бэкап, детекция)
│   │   └── views/         # Основные разделы (Древо, Граф, Таймлайн, Архив, Справочник)
│   ├── data/              # Демонстрационные исторические данные (семья Морозовых)
│   ├── services/          # Сервисы БД IndexedDB и распознавания лиц
│   ├── types/             # TypeScript-интерфейсы родословной и родства
│   ├── utils/             # Утилиты родственных связей (kinship)
│   ├── App.tsx            # Главный компонент приложения
│   └── main.tsx           # Точка входа
├── launcher.cs            # Исходный код нативного Windows-лаунчера
├── compile-exe.bat        # Батник для сборки EXE-файла
└── vite.config.ts         # Конфигурация Vite
```
