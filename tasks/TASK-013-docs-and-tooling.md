# TASK-013: Документация, лицензия и инструменты разработки

**Приоритет:** P2
**Статус:** не начато

## Проблема

README указывает Node 18, хотя Vite 8 требует более новую версию, описывает удалённый CDN fallback и представляет C# launcher как автономное native-приложение. Файл `LICENSE` отсутствует, версии npm/Cargo/Tauri расходятся, `clean` использует Windows-несовместимый `rm -rf`, а `start-windows.bat` открывает браузер до готовности сервера.

## Объём работ

- Обновить минимальную версию Node и добавить `engines` в `package.json`.
- Актуализировать описание локальных моделей, IndexedDB и Tauri-хранилища.
- Добавить полный текст MIT `LICENSE` либо изменить заявленную лицензию.
- Синхронизировать версии `package.json`, Cargo и Tauri config.
- Заменить `clean` на кроссплатформенную реализацию.
- Исправить Windows start script: сначала сервер, затем health-check и браузер.
- Решить судьбу legacy `launcher.cs`/`compile-exe.bat`.
- Добавить portable EXE в `.gitignore` или публиковать артефакт через GitHub Releases.

## Принятые решения

- `launcher.cs` и `compile-exe.bat` удаляются; единственная поддерживаемая desktop-сборка — Tauri.
- Версия релиза должна задаваться в одном месте и синхронизироваться в остальные manifest-файлы автоматизированной проверкой.
- Пользовательские бинарные артефакты публикуются через GitHub Releases и не хранятся в рабочем дереве.
