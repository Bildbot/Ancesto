# TASK-006: Лимиты размера медиа и бэкапов

**Приоритет:** P1
**Статус:** не начато

## Проблема

`src/services/media.ts:17` проверяет тип, но не размер файла, после чего читает его целиком в Base64. Одновременно native backup ограничен 100 МБ ZIP и 512 МБ распакованных данных. Пользователь может создать архив, который невозможно штатно экспортировать или восстановить.

## Объём работ

- Определить лимиты отдельно для фото, документов и видео.
- Проверять размер до `FileReader` и до передачи данных через IPC.
- Согласовать лимит одного файла, общий размер архива и лимиты ZIP-восстановления.
- Показывать понятное сообщение с фактическим и допустимым размером.
- Для Tauri по возможности передавать путь или поток вместо Base64.
- Задокументировать ограничения браузерной и desktop-версии.

## Принятые решения

- Лимиты различаются для браузера и desktop: браузерные ограничения строже из-за Base64, IndexedDB и доступной памяти.
- Первая версия только отклоняет слишком большие файлы с понятным сообщением; автоматическое сжатие не входит в эту задачу.
- Точные значения определяются по замерам памяти, времени импорта и размера backup до начала реализации.
