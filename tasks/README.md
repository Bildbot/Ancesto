# Задачи проекта

Этот каталог содержит задачи, выявленные при техническом обзоре проекта. Каждая задача имеет собственный файл, приоритет, зависимости и отдельный чек-лист готовности.

## Обозначения

- `P0` — риск потери данных, нарушения приватности или основной функции.
- `P1` — существенная проблема надёжности, производительности или качества.
- `P2` — улучшение UX, сопровождения или процесса разработки.
- Статусы: `не начато`, `в работе`, `заблокировано`, `готово`.

## Зависимости

- `TASK-001` и `TASK-002` фиксируют текущие контракты данных до крупного рефакторинга.
- `TASK-009` должна опираться на регрессионные тесты из `TASK-001` и `TASK-002`.
- `TASK-007` удобнее выполнять после определения целевой модели в `TASK-009`, но устранение полной Base64-гидратации можно сделать отдельным этапом.
- `TASK-010` можно начинать сразу; тесты конкретных дефектов должны добавляться вместе с соответствующими задачами.
