# TASK-005: Безопасный импорт медиа и CSP

**Приоритет:** P0
**Статус:** не начато

## Проблема

Импорт проверяет у `dataUrl` только тип `string` (`src/services/db.ts:56`). В результате недоверенный архив может передать внешний URL в `<img src>` и инициировать сетевой запрос. В Tauri CSP отключена в `src-tauri/tauri.conf.json:22`, что ослабляет второй уровень защиты.

## Объём работ

- Разрешить только ожидаемые локальные схемы (`data:` и внутреннюю media-схему приложения).
- Проверять разрешённый MIME-тип, сигнатуру и согласованность расширения.
- Отклонять `http:`, `https:`, `file:` и неожиданные URI до изменения текущего дерева.
- Включить строгую CSP для Tauri без внешних `connect-src` и `img-src`.
- Убедиться, что локальные модели распознавания и custom protocol продолжают работать.
- Не выводить непроверенный HTML из импортированных полей.

## Проверки

- Импорт архива с внешним URL отклоняется без сетевого запроса.
- Валидные локальные изображения и документы импортируются.
- Desktop smoke-test проходит с включённой CSP.
- Проверка network log подтверждает отсутствие внешних запросов.

## Готовность

- [ ] Внешние и неизвестные URL блокируются валидатором.
- [ ] MIME-тип проверяется по содержимому, где это возможно.
- [ ] В Tauri включена и задокументирована CSP.
- [ ] Локальные модели, медиа и backup работают после изменения.
- [ ] Добавлены негативные тесты импорта.
- [ ] Приватность подтверждена desktop smoke-test.
