# TASK-011: Безопасный и полноценный PWA-кэш

**Приоритет:** P2
**Статус:** выполнено

## Проблема

`public/sw.js:12` удаляет все кэши origin, кроме текущего, хотя CacheStorage общий для origin. Это может затронуть другие приложения на том же GitHub Pages origin. Precache не включает собранные JS/CSS и модели, поэтому гарантированный offline startup отсутствует.

## Объём работ

- Удалять только кэши с уникальным префиксом приложения.
- Генерировать precache manifest из Vite assets.
- Определить стратегию кэширования моделей распознавания и крупных ресурсов.
- Добавить безопасное обновление Service Worker без потери пользовательских данных.
- Сохранить отключение PWA-регистрации в Tauri.

## Проверки

- Offline startup после первой установки.
- Обновление на новую версию ресурсов.
- Чужой кэш того же origin не удаляется.
- Desktop-версия не регистрирует Service Worker.

## Готовность

- [x] Service Worker управляет только кэшами приложения с уникальным префиксом.
- [x] Основные JS/CSS/assets включены в генерируемый Vite precache manifest.
- [x] ML-модели кэшируются при первом обращении (cache-first после загрузки), чтобы не скачивать ~12 МБ при установке.
- [x] Worker не вызывает `skipWaiting`; обновление активируется штатно после закрытия контролируемых старых вкладок.
- [x] Добавлен Playwright offline smoke-test на production-сборке.
- [x] Поведение web и Tauri задокументировано.
